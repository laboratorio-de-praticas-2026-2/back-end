# back-end
O Back-end do Portal Contábil é responsável pelas regras de negócio, gerenciamento de dados e integração entre os serviços da plataforma. Ele fornece APIs para autenticação, informações contábeis e fiscais, serviços, agendamentos, usuários e solicitações, garantindo segurança, organização e comunicação eficiente com o front-end.
